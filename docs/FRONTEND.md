
# Frontend Documentation

## 1. Overview

The frontend of the Real-Time Face Shape Detection project is built using HTML, CSS, and Flask's Jinja2 template engine.

It provides three main pages:

- Home page (`index.html`)
- Image upload page (`upload.html`)
- Real-time face detection page (`real_time.html`)

The templates communicate with the Flask backend through routes defined in `app.py`.

## 2. Home Page – index.html

The home page provides the main navigation interface.

### Features
- Displays the Face Shape Detection heading.
- Provides an Upload Image link.
- Provides a Real-Time Camera Feed link.
- Uses the shared stylesheet from `static/styles.css`.

### Navigation
- Upload Image: Opens the `/upload` route.
- Real-Time Camera Feed: Opens the `/real_time` route.

## 3. Image Upload Page – upload.html

The upload page allows users to submit an image for face shape detection.

### Upload Form
- Uses the HTTP POST method.
- Uses `multipart/form-data` encoding.
- Accepts a file through an input named `file`.
- Provides an Upload submit button.

### Result Display

The page uses Jinja2 conditional statements to display information supplied by the Flask backend.

- **Selected file:** Displays the filename when the `file` variable is available.
- **Face shape:** Displays the predicted face shape when `face_shape` is available.
- **Error message:** Displays an error when the `error` variable is available.
- **Annotated image:** Displays the processed image when `file_url` is available.

### Styling
The page includes styling for:
- Upload container and form
- File selection text
- Upload button and hover effect
- Face shape result
- Error messages
- Annotated image display
- Home navigation link

The annotated image is constrained to a maximum height of 400 pixels and uses `object-fit: contain` to preserve its proportions.

## 4. Real-Time Detection Page – real_time.html

The real-time page displays the video feed generated by the Flask backend.

### Features
- Displays a Real-Time Face Detection heading.
- Embeds the video feed using an HTML image element.
- Retrieves the feed from the `/video_feed` route.
- Provides a link to return to the home page.

The video feed is supplied by the Flask backend rather than generated directly by the HTML template.

## 5. Styling and Design

The frontend uses CSS to organize and style the application.

- `static/styles.css` is referenced by all three templates.
- The upload page also contains additional inline CSS.
- Arial is used as the font on the upload page.
- Buttons, containers, result text, error messages, and images have dedicated styling.

## 6. Frontend–Backend Integration

The frontend communicates with the Flask application through its routes and template variables.

| Frontend Component | Backend Integration |
|---|---|
| Home page | `/` |
| Image upload | `/upload` |
| Real-time page | `/real_time` |
| Video feed | `/video_feed` |
| Selected filename | `file` |
| Prediction result | `face_shape` |
| Error display | `error` |
| Annotated image | `file_url` |

## 7. Project Template Structure

```text
templates/
├── index.html
├── upload.html
└── real_time.html
```

The frontend works with the Flask backend to provide image-based and real-time face shape detection functionality.
